## 坐标、单位与相同粒子

横轴直接使用 EXFOR 的 `ANG-CM`，为质心系中探测到的出射质子的极角。pp 的两个出射质子不可区分，因此理论未极化微分截面对 θ 与 180°−θ 对称，但本图不镜像复制实验数据，不把后半球数据折叠到前半球，也不额外乘 2 或除以 2。

测量主要覆盖一个半球；3.037、9.69 和14.16 MeV记录有少量大于90°的原始点，按原角度保留。高能 EDDA 三图仅覆盖约51°–89°，不能从这几组实验点独立判断其整个角分布。

纵轴统一为 mb/sr。3.037 MeV 的原始单位是 b/sr，依照1 b = 1000 mb转换；这是标准单位换算，没有 np 284 MeV 时的经验单位重解释。其余所选 pp 数据本身已用 mb/sr。原值、原单位、换算后单位分别保留在CSV列中。

## 误差棒与共同误差

图上优先用 `ERR-T`，否则 `DATA-ERR`，否则 `ERR-S`。百分比误差乘以相应实验值；不擅自把独立、相关或不同置信定义的误差合并。所有原始误差字段（包括共同归一化误差）仍在 `errors_original_json` 和 QueryOutcome 中。

- **3.037 MeV**：`DATA-ERR` 是论文给出的非系统误差，单位为百分比；数据归一化到同一实验的1.855 MeV标准化测量。完整系统误差需要参考原论文表II，EXFOR没有一项可直接作为全部误差棒的总系统误差。
- **9.69 MeV**：`ERR-T` 为 absolute probable error（或然误差），**不等同于默认的一倍标准差**；`ERR-1` 为 relative probable error。图直接保留作者误差定义，不进行置信水平重解释。EN-ERR = 0.03 MeV。
- **14.16 MeV**：`ERR-T` 为总不确定度，百分比。EN-ERR = 0.07 MeV，EN-RSL = 0.5%；不把两项能量信息加到截面误差棒。
- **50.06 MeV**：`ERR-S` 为逐点统计误差并包含背景扣除和监测误差；另有1.6%的共同归一化误差，**未加入逐点误差棒**。EN-ERR = 0.04 MeV。
- **98、142 MeV**：图用表内 `DATA-ERR`。COMMON另外报告4.5%的绝对尺度误差（DATA-ERR1）、2%的总相对误差（DATA-ERR2）及分项。原始误差分析还说明独立绝对尺度测定之间有3%–4%的相对误差；不重复平方相加。FLAG=1/2表示使用小角/大角望远镜。两个子记录及原FLAG均保留，不平均重合角点。
- **239.9、270.8、286.7 MeV（EDDA）**：`ERR-T`已是逐点不相关误差 ERR-S 与缓变系统误差 ERR-1 的平方和开根号。它**不包含**全数据集小于1.5%的总体归一化误差，以及同一能量各点共同的2.5%相对归一化上限；后者在不同能量之间不相关。不能把190点的误差全当成独立高斯标准差计算简单总体χ²。

## 能量选取与排除

本轮优先选取能量分散且直接给出CM角度和绝对截面的数据，没有为了凑整数能量做插值或能量平均。50.06 MeV点来自表格且误差结构较清楚。局部数据库没有约25 MeV的这类多角表；约200 MeV有LAB资料，但参考系变换和归一化依赖会增加本轮比较的解释负担，因此选取明确CM的14.16与239.9 MeV等点。

9.69 MeV查询还返回 A1047002、C0047002，它们仅显式标注LAB角，工具明确排除并保存在每个panel的 `excluded` 中。190 MeV O1226002 的实验绝对尺度拟合SAID/PWA，不选作本轮完全独立绝对尺度核验。300 MeV C2643002仅7个图上读取的小角点，本轮高端采用作者数值表中的286.7 MeV EDDA数据。

这些选择服务于本轮对比图，不意味着被排除的实验不正确或没有研究价值。
