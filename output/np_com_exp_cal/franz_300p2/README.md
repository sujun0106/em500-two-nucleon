# np 高能实验数据包（2026-09-25）

本目录保存实验数表及溯源记录，Fortran计算位于上级比较目录。研究时使用的论文、网页和截图保存在本地研究档案；公开版从[原站链接](../SOURCE_LINKS.md#franz)获取。历史“原始文件”指数据库HTTP响应和论文，并非实验原始事件文件。

## 首选：Franz 2000，300.2 MeV

来源：J. Franz, E. Rössle, H. Schmitt, L. Schmitt, *The PSI np data and their effect on the charged πNN coupling constant*, Physica Scripta T87 (2000) 14–21，[作者预印本](https://arxiv.org/abs/hep-ph/0004253)，[DOI](https://doi.org/10.1238/Physica.Topical.087a00014)。数表来自 [NN-OnLine](https://nn-online.org/NN/nn.php?program=Showdata&c=221&g=2250225122522253)。

- 反应：自由 np 弹性散射；连续中子束入射液氢，测量反冲质子，不是从氘核准自由散射提取。
- 标称入射中子实验室动能：300.2 MeV。论文按 **20 MeV 能量区间** 分箱；300.2 MeV 不是单色束能量。精确事件能量权重和各组实际分箱边界未从本次数表得到。
- 观测量：质心系中子散射角对应的微分截面；4 个子组共 111 点，79.8–179.2 度。有重叠角度，不能删重或把它们误当独立绝对归一化实验。
- NN-OnLine 给的是相对截面，最大角 179.2 度归一为 1。原文 Table I 第 10 列给出该能量的绝对因子 **10.63 mb/sr，误差 3.1%**，已据原论文第6页目视核验；历史截图名为 `Franz2000_TableI_page6.png`，公开版获取原文见[来源链接](../SOURCE_LINKS.md#franz)。
- `tables/FR00_g2250.csv` 至 `FR00_g2253.csv` 保留相对数值；`tables/FR00_300p2_absolute_derived.csv` 是本项目派生绝对表，数值和逐点误差均乘 10.63。派生表不是另一组实验数据。
- 逐点误差照录，不冒称纯统计误差。论文给出统计及额外系统误差处理；跨点协方差未随本次数表获得。3.1% 为共享归一化误差，CSV 中重复出现只为方便读取，**不能作为各点独立随机误差重复计数**。组间相对归一化还需考虑论文所述关联，正式 χ² 分析前必须写明协方差近似。
- 论文同时测量的 np→dπ0 用于绝对归一化；此包选取的观测量仍是 np→np 弹性截面。

## 补充来源对照：Keeler 1982，319 MeV

来源：R. K. Keeler et al., *Neutron-proton scattering cross sections between 200 and 500 MeV*, Nucl. Phys. A377 (1982) 529–553，[原论文摘要](https://doi.org/10.1016/0375-9474(82)90054-9)。自由中子束入射液氢；中子产生反应是 D(p,n)，不意味着观测量是准自由 np。

历史研究档案记录了 NN-OnLine 组2074（前角7点，11.13–94.52度）和2075（后角64点，66.73–177.02度）的原响应及照录CSV；公开版仅保留来源记录，原站地址见[历史来源](../SOURCE_LINKS.md#historical)。数据库分别注明：前角归一化误差 2%，但在其 PWA 中浮动；后角归一化 1±0.039。数据库标记不是实验重新测得的误差。

历史项目曾由正式 EXFOR Tool 取得 12884003、12884004，并以 `exfor_high_energy` 标记另外保存的核对材料；该历史材料未纳入本目录，也不参与当前300.2 MeV比较图的生成。不同库可能保留了 PWA 重归一化或修正，**此处两份 NN-OnLine 表暂作为数据库交叉核对件，未宣称与原论文逐点数值完全相同**。在两个来源完成修正历史对账前，不将它们相加，也不把不同数值平均。实验能宽和完整归一化协方差仍待原文全文核查。

## 格式、解析和核验

`manifest.json` 记录历史获取时间、URL、HTTP状态、文件字节数和SHA-256；历史文件清单用于追溯上游原件，公开版现存文件列于 `files`。原网页通过NN-OnLine的公开Search→Showdata页面取得，HTTP响应字节留在本地研究档案，公开版从[原站](../SOURCE_LINKS.md#franz)重新取得。解析仅去除 HTML 标签、解码 HTML 实体、读取形如“MeV, deg., DSG=value±error”的数据行，保留原组顺序和所有点。未拟合、插值、删点、读取图像点或利用相移解重归一化。

解析已核对点数 27+33+27+24=111 及 7+64=71、正误差、角度范围、源表逐点字段。绝对派生表逐点验证为相对表×10.63；179.2 度的值应为 10.63 mb/sr。CSV 的 `point_uncertainty` 是原库逐点误差；`normalization_fraction` 是分数而非百分数。

300 MeV 左右已存在产生实 pion 的开放道，而既定 EM2003 NN 力的原拟合能区截至 290 MeV。应把此组定位为接近目标上限的模型适用性检验，区分数值收敛、核力外推和缺少非弹性道的误差。

数据用于本项目科研核验。公开可读取不等于有自由再发布许可；源网页和论文未在此包重新授予许可，本公开版以[来源链接](../SOURCE_LINKS.md)替代这些第三方原件，并保留提取后的科学数据与原件下载哈希。
